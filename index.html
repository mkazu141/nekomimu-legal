Nekomimu Uploader

Personal video scheduling tool for a single creator / 個人クリエイター向けの動画予約投稿ツール

Overview / 概要

Nekomimu Uploader is a command-line tool that a single creator (the operator) runs on their own Windows PC. It renders short educational videos from local script files and schedules them to the operator's own social media accounts, including TikTok via the Content Posting API. It is not a service for other users: there is no sign-up, no hosting, and no third-party access.

Nekomimu Uploaderは、運用者本人が自分のWindows PC上で実行するコマンドラインツールです。ローカルの台本ファイルから教育系ショート動画を生成し、運用者自身のアカウント（TikTokはContent Posting API経由）へ予約投稿します。第三者向けのサービスではなく、登録機能もホスティングもありません。

Features / 機能

Schedule ledgerTracks which videos are planned / scheduled to prevent duplicate posting.npm run plan:posts

How it works / 動作原理

  1. Write a script — The operator (or an AI assistant) writes a JSON script file describing scenes, on-screen text and the source video assets stored on the local PC.
  2. Render — The tool composes the scenes with ffmpeg into a single MP4 on the local disk. Nothing is uploaded at this stage.
  3. Validate — Resolution, duration, title and publish time are checked automatically. Invalid files are rejected before any API call.
  4. Authorize — On first use, the operator authorizes the app with their own TikTok account via Login Kit (OAuth 2.0 with PKCE, loopback redirect http://localhost:<port>/callback/). The refresh token is stored in a local file that is excluded from version control.
  5. Post — The tool calls /v2/post/publish/video/init/ (Direct Post) or /v2/post/publish/inbox/video/init/ (draft), uploads the file with a single-chunk PUT, then polls /v2/post/publish/status/fetch/ until the status becomes PUBLISH_COMPLETE.
  6. Record — The result (publish id, timestamp) is written to a local ledger file so the same video is never posted twice.

Example session / 実行例

$ npm run auth:tiktok
以下のURLをブラウザで開き、投稿先のTikTokアカウントで許可してください:
https://www.tiktok.com/v2/auth/authorize/?client_key=...&scope=user.info.basic,video.upload,video.publish...
認可完了。スコープ: user.info.basic,video.publish,video.upload / トークンを保存しました（自動更新されます）

$ npm run tiktok:post -- --story stories/example.json
投稿: outputs/mov/example.mp4
タイトル: 会議の文字起こし×AIで先輩のファシリを分解した話 #猫ミーム #AI活用
公開範囲: SELF_ONLY
完了: publish_id=v_pub_file~v2-1.76667... status=PUBLISH_COMPLETE

Scopes used / 使用スコープ

  • user.info.basic — confirms which account the tool is authorized for (shown in the console after login).
  • video.publish — used by the Direct Post flow to publish scheduled videos to the operator's profile.
  • video.upload — used by the draft flow (--draft) to send a video to the operator's TikTok inbox for manual editing.

Data handling / データの扱い

  • Access and refresh tokens are stored only on the operator's local PC (config/secrets/, excluded from git). They are never transmitted to any third party.
  • Video files are created and stored locally; only the file the operator selects is uploaded to TikTok.
  • No data from other TikTok users is collected, stored, or processed.
  • Access can be revoked at any time from TikTok settings; deleting the local token file removes all stored credentials.
This tool is used by one person only (the operator). There is no public sign-up page and no login page for other users — the "website" is this documentation.

Environment / 動作環境

  • Windows 11 / Node.js 22+ / ffmpeg
  • Run manually from the terminal, or on a schedule via Windows Task Scheduler
  • Posting volume: up to 3 videos per day (well under the API limit of 25/day)
