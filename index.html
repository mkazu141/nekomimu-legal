Nekomimu Uploader

Personal video scheduling tool / 個人用の動画予約投稿ツール

What is this? / これは何？

Nekomimu Uploader is a personal automation tool operated by an individual creator. It schedules and uploads the operator's own original educational short videos (cat-meme style knowledge content) from local storage to the operator's own social media accounts. It is a single-user tool with no public sign-up.

Nekomimu Uploaderは、個人クリエイターが自作の教育系ショート動画（猫ミーム知識コンテンツ）を、自身のアカウントへ予約投稿するための個人用自動化ツールです。利用者は運用者本人のみで、一般向けの登録機能はありません。
